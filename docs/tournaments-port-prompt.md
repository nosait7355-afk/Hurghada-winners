## المتطلبات (اتفقنا عليها مع العميل)
- **نوع اللعبة:** فردية (كل مشارك لاعب واحد) أو جماعية (كل مشارك فريق). في الجماعي **الأدمن هو اللي يختار لاعبي كل فريق يدوياً** ويحدد كابتن (اختياري). اللاعب ما ينفعش يكون في مشاركَين في نفس البطولة.
- **نظام البطولة:** دوري (كل فريق ضد الكل، مرة أو ذهاب وعودة) / كأس خروج مغلوب / مجموعات ثم كأس.
- **القرعة:** عشوائية (النظام يخلط) أو موجّهة (الأدمن يرتّب المشاركين بالسحب، والأول = المصنف 1)، والأدمن يقدر يبدّل طرفي أي مباراة قبل تسجيل أي نتيجة.
- **طريقة النتيجة:** أهداف/نقاط (رقم لكل طرف) أو **أشواط** للألعاب الفردية؛ إعدادات الأشواط في فورم الإنشاء: عدد الأشواط (أفضل 1/3/5/7 — فردي فقط)، نقاط الشوط، الفوز بفارق نقطتين، وحد أقصى اختياري للشوط.
- **التعادل في الكأس:** ضربات ترجيح، والأدمن يفعّلها ويحدد عددها في فورم الإنشاء. في الدوري: إعداد "التعادل مسموح" + نقاط الفوز/التعادل/الخسارة (افتراضي 3/1/0).
- **اللاعبين يشوفوا البطولات** في بوابتهم (قراءة فقط): البطولات اللي جدولها اتنشر، ومبارياتهم وفريقهم مميزين.
- **بدون أنواع حسابات جديدة** — استخدم الأدوار الإدارية الموجودة.
- إشعار للاعبين عند نشر الجدول وعند تسجيل نتيجة (لو التطبيق فيه نظام إشعارات).

- **Tournament:** (معرّف المؤسسة لو التطبيق متعدد المؤسسات)، الاسم، الرياضة، الفئة العمرية، تاريخ بداية/نهاية، ملاحظات، `participantType` (individual|team)، `format` (league|knockout|groups_knockout)، `drawMode` (random|directed)، `scoring {mode: goals|sets, bestOf, pointsPerSet, winByTwo, maxPointsPerSet}`، `league {winPoints, drawPoints, lossPoints, doubleRound, allowDraws}`، `groups {count, qualifiersPerGroup}`، `knockout {penaltiesEnabled, penaltiesCount}`، `status` (draft|running|finished)، `visibleToPlayers`.

- **Fixture (مباراة بطولة — منفصلة عن أي نموذج مباريات موجود لو مفيهوش نتيجة وطرفين):** tournamentId، stage (league|group|knockout)، groupIndex، round، matchNo، aId، bId، scoreA، scoreB، sets[{a,b}]، penaltiesA/B، winnerId، status (pending|played|bye)، nextMatchNo + nextSlot (a|b) للكأس، date، time، location.

## المنطق (اكتبه كدوال نقية مع اختبارات وحدات أولاً)
- **الدوري:** خوارزمية الدوران (circle method)؛ عدد فردي ⇒ "راحة" كل جولة؛ تبديل الأرض بالتناوب؛ ذهاب وعودة = تكرار الجولات بالأطراف معكوسة. لازم كل زوج يتقابل مرة واحدة ومحدش يلعب مرتين في نفس الجولة.
- **الكأس:** حجم الشجرة = أقرب قوة لـ 2؛ ترتيب المقاعد القياسي (1 ضد الأخير، و1 و2 ما يتقابلوش قبل النهائي): ابدأ بـ [1] وكل خطوة `s → [s, len+1-s]`. المقاعد الزيادة = صعود مباشر (bye) لأعلى المصنفين ويتنقل الفائز تلقائياً للدور التالي. فائز كل مباراة يتنقل لمقعده في المباراة التالية (`nextMatchNo = ceil(m/2)`، `nextSlot = m فردي ? a : b`).
- **المجموعات:** توزيع ثعباني (snake) على المجموعات؛ دوري داخل كل مجموعة؛ عدد المتأهلين لازم يكون أقل من حجم أصغر مجموعة؛ لما كل مباريات المجموعات تخلص تتعمل شجرة الكأس تلقائياً من المتأهلين بترتيب (أوائل المجموعات ثم الثواني...) بحيث أبناء نفس المجموعة ما يتقابلوش في أول دور.
- **التحقق من الشوط:** لازم الفائز يوصل لنقاط الشوط؛ مع "فارق نقطتين": الفارق ≥ 2، ولو عدّى الهدف يبقى الفارق = 2 بالظبط، إلا لو وصل للحد الأقصى (يكسب بنقطة). بدون فارق نقطتين: الفائز = نقاط الشوط بالظبط. المباراة تنتهي أول ما حد يكسب ceil(bestOf/2) أشواط وما يتقبلش أشواط بعدها.
- **النتيجة:** أهداف متساوية في الدوري = تعادل (أو رفض لو التعادل مش مسموح)؛ في الكأس = لازم ترجيح بفائز واضح لو مفعّل، وإلا رفض.
- **الترتيب:** نقاط ← فارق ← له ← المواجهات المباشرة بين المتساوين تماماً. في الأشواط "له/عليه" = الأشواط.
- **حالة البطولة:** draft لحد توليد الجدول ← running ← finished لما كل مباريات الدوري تخلص أو النهائي يتلعب (وترجع running لو اتمسحت نتيجة).

## الـ API (أو ما يعادله في بنية التطبيق)
إدارة: قائمة/إنشاء/تعديل/حذف بطولة؛ إضافة/تعديل/حذف مشارك؛ حفظ ترتيب القرعة الموجّهة؛ توليد الجدول؛ حذف الجدول (يرجع draft)؛ تعديل مباراة (موعد/مكان، وتبديل الطرفين قبل أي نتيجة وفي الدور الأول بس للكأس ونفس المجموعة)؛ تسجيل/مسح نتيجة؛ تفاصيل البطولة = البطولة + المشاركين + أسماء اللاعبين + المباريات + الترتيب محسوب.
لاعب: قائمة البطولات الظاهرة وغير الـ draft مع علامة "مشارك"، وتفاصيل بطولة مع `myParticipantId` (من غير بيانات حساسة للاعبين التانيين).

**قواعد مهمة:**
- الإعدادات (النوع/النظام/القرعة/النتيجة/المجموعات...) والمشاركين يتعدّلوا في draft بس؛ الاسم والتواريخ والملاحظات والظهور في أي وقت. التعديل الجزئي للإعدادات المتداخلة يدمج ما يمسحش الباقي.
- ممنوع إعادة توليد/حذف الجدول بعد أي نتيجة.
- ممنوع تسجيل/مسح نتيجة مباراة كأس لو المباراة اللي بعدها اتلعبت.
- تعديل نتيجة في المجموعات بعد ما الشجرة اتعملت: لو مفيش مباراة كأس اتلعبت امسح الشجرة وأعد بناءها، وإلا ارفض.
- الصلاحيات: الأدوار الإدارية الموجودة بس هي اللي تدير البطولات، واللاعب قراءة فقط. اللاعبين المضافين لازم يكونوا نشطين (ومن نفس المؤسسة لو التطبيق متعدد المؤسسات).

## الواجهة
- **أدمن:** زر "البطولات" في لوحة التحكم ← قائمة (الاسم، النظام، النوع، العدد، حالة ملونة) ← فورم إنشاء/تعديل (الأقسام تظهر حسب الاختيار: الأشواط لو sets، نقاط الدوري لو مش كأس، المجموعات لو groups_knockout، الترجيح لو فيه كأس + أهداف) ← صفحة البطولة بـ 3 تبويبات: **المشاركون** (إضافة فريق باسمه واختيار لاعبيه بالبحث وتحديد الكابتن، أو اختيار لاعب في الفردي؛ سحب لترتيب القرعة الموجّهة؛ زر توليد الجدول)، **المباريات** (مقسّمة بالجولة/المجموعة/دور الكأس: نصف النهائي، ربع النهائي...)، **الترتيب** (جدول لكل مجموعة/دوري مع تمييز المتأهلين + شجرة كأس أفقية). الضغط على مباراة ← نافذة: تسجيل النتيجة (خانات الترجيح تظهر تلقائياً عند التعادل في الكأس؛ خانة لكل شوط)، مسح النتيجة، الموعد والمكان، تبديل الطرفين.
- **لاعب:** زر "البطولات" في صفحته الرئيسية ← بطولاته أولاً ← صفحة البطولة: بطاقة فيها فريقه وزمايله والكابتن ومركزه ونقاطه + تبويبات "مبارياتي / كل المباريات / الترتيب" مع تمييز فريقه. إشعارات البطولة تفتح الصفحة دي.
- رسائل الأخطاء من السيرفر تظهر للمستخدم كما هي، وكل النصوص عربي و RTL لو التطبيق عربي.
